## ✨ About Mefil

**Mefil** is a listen-together experience built to make sharing music feel effortless. The idea is simple: bring people together through music with a real-time listening experience.

I wanted to keep things lightweight and focus on building the actual experience rather than introducing unnecessary abstractions.

- **No frontend framework** — just the fundamentals of the web.
- **Real-time communication** — Socket.IO handles live communication between connected clients.
- **Lightweight backend** — Node.js and Express keep the server straightforward.
- **Simple architecture** — fewer layers, less overhead, and easier maintenance.

Sometimes, keeping things simple is the best engineering decision.

## 🚀 Getting Started

Want to run Mefil locally? Follow these steps.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone <YOUR_REPOSITORY_URL>
```

**2. Navigate to the project directory**

```bash
cd mefil
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the application**

Use the start command configured in your `package.json`. For example:

```bash
npm start
```

**5. Open the application**

Visit the local URL printed by your server in the terminal.

> **Note:** Replace the repository URL and startup command with the actual values for your project, if they differ.
