Mehfil SVG Icon Pack

Contains individual editable SVG icons for a minimalist music-themed website.
All icons use currentColor with a default muted beige color (#D8D0C2).

Usage:
  <img src="/icons/music-note.svg" alt="" />

To recolor with CSS when embedding inline:
  svg { color: #D8D0C2; }

Icons are original simple vector drawings generated for this pack.
